# CityCabs24 - Premium Cab & Guided Tour Booking Platform 🚖

A modern, high-performance web application for cab booking and guided sightseeing tours across Mumbai, Pune, Lonavala, Shirdi, Konkan, and outstation routes.

🌐 **Live URL**: [https://citycabs24.com](https://citycabs24.com) / [https://cabs.kishorlab.dev](https://cabs.kishorlab.dev)

---

## ✨ Features

- 🏎️ **Interactive Cab Booking Widget**: One-way, Round-trip, Local hourly rental, and Custom Tour packages.
- 🗺️ **Comprehensive Tour Packages**: Mumbai Darshan, Lonavala-Khandala, Alibaug Beaches, Matheran Eco Hills, Shirdi, Mahabaleshwar-Panchgani, Igatpuri, Ashtavinayak Darshan, 3 Jyotirlinga, and Konkan Coastal Roadtrip.
- 🚘 **Fleet Showcase**: Detailed specs, seating capacity, luggage limits, and pricing for Sedan (Dzire), SUV (Ertiga, Carens), and Premium (Innova Crysta).
- 💰 **Dynamic Fare Calculator**: Instant fare estimation across major routes with transparent toll/driver fee breakdown.
- 🧭 **Driver-As-A-Guide**: Driver-guide profiles, verified ratings, safety standards, and local knowledge.
- 📱 **Instant Booking & Support**: One-click WhatsApp booking, direct phone call action buttons, and automated booking inquiry form.
- ⚡ **Optimized Performance**: Vite 6, Tailwind CSS 3, Dockerized Nginx Alpine with gzip compression and cache headers.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 6, Tailwind CSS 3, Lucide React Icons
- **Deployment**: Docker, Docker Compose, Nginx Alpine, Traefik Reverse Proxy, Cloudflare CDN
- **Fonts**: Outfit, Plus Jakarta Sans, Caveat

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/Kishorshinde112/Citycabs24.git
cd Citycabs24

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🐳 Docker Deployment

```bash
# Build and run with Docker Compose
docker compose up -d --build
```
